## 🧪 Troubleshooting Common Issues

Even with a simple tool, sometimes things can go wrong. Here are quick fixes for the most common problems.

### ❌ Tool Won’t Start

If nothing happens when you double-click the file:

1. Right-click the file and select **"Run as administrator"**
2. Make sure your antivirus isn’t blocking it (temporarily disable it and try again)
3. Restart your computer and try again

### 🐌 Tool Is Laggy

If the tool feels slow:

- Close other programs running in the background
- Update your graphics drivers
- Lower the visual quality settings in the tool

### 🖥️ Game Not Detected

If the tool says it can’t find your game:

- Make sure the game is running before launching the tool
- Try running both the game and the tool as administrator
- Check if you have the latest version of the game installed
